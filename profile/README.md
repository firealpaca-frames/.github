# FireAlpaca - Paint on Your Own Canvas

FireAlpaca is a painting program for pictures you make. Layers keep a sketch apart from color. Frames, if you use them, are drawings you added. The program does not supply a finished illustration to trace from a commercial work.

---

## Product Snapshot

Open a new canvas at a modest size. Sketch on one layer and color on another. If a stroke is wrong, undo or hide the layer. Export only when you want a file someone else can view. Name the export so it is not the only copy of the layered document.

Brushes and stabilizers are comfort. They do not back up the file. A tablet is optional. A mouse is enough to learn the window. If you import a photo, it must be one you may paint over. FireAlpaca will not remove a watermark, and tracing a page you do not own is not a study file.

## Live Production

Use it for a sketch, a comic panel you write, or a simple animation of a pose you invented. Save, then export, then open the PNG outside FireAlpaca. If the export is the wrong size, change the canvas and export again. Do not flatten the only layered file until you have saved a spare.

A reference photo you took can sit on a layer you hide before you export. A reference you do not have rights to should not be in the file you publish.

---

## Layers You Can Hide

Name the sketch layer and the color layer. Hide the sketch to see what the export will include. If a layer still shows a photo you did not mean to ship, hide it and export again. The layered file can keep the photo for you. The PNG you send should not.

---

## Setup Path

Prerequisites: Time to draw, and a folder for the working file and the export.

1. Install FireAlpaca and create a small canvas.
2. Draw on two layers and save the working file.
3. Hide a layer and look at what remains.
4. Export a PNG with a new name.
5. Open the PNG outside FireAlpaca. Keep the working file.

## Who Benefits

FireAlpaca fits drawings you make and a layered file you can reopen. It does not fit removing a watermark, tracing work you do not own, or an export-only habit that never saves the layers.

---

## Fixes

The export is blank: the visible layers were hidden or empty. The canvas feels huge and slow: start smaller. You lost the painting: it was not saved. Save earlier. A photo you do not own is still in the PNG: hide that layer and export a new file.
